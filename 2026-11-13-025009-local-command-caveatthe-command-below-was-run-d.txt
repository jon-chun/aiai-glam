       21 +## What it is                                                 
       22 +                                                              
       23 +Archival Intelligence AI is a full-stack web application that 
          +runs on an institution's own machine.                         
       24 +It brings the main steps of collection work into one place:   
       25 +                                                              
       26 +1. **Intake.** Import files and source metadata, preview what 
          +will be stored, and record rights decisions before anything is
          + committed.                                                   
       27 +2. **Preservation.** Keep every original byte-for-byte, with c
          +hecksums and an append-only event log that detects tampering. 
       28 +3. **AI assistance.** Run optional local or commercial models 
          +for OCR, transcription, description, translation, entity extra
          +ction and embeddings. Every result is a *candidate*, never a f
          +act.                                                          
       29 +4. **Human review.** Compare candidates against the source, co
          +rrect them, and approve a specific, frozen revision.          
       30 +5. **Discovery.** Search, browse an evidence-linked graph, and
          + view images, audio, video and text in the browser.           
       31 +6. **Publication.** Publish only what rights allow, and withdr
          +aw it from every public surface at once when they change.     
       32 +7. **Exchange and recovery.** Export to common archival format
          +s, and back up and restore the whole archive.                 
       33 +                                                              
       34 +## Principles                                                 
       35 +                                                              
       36 +- **Originals are never overwritten.** Preservation Originals 
          +and Interpretive Derivatives are stored and labelled separatel
          +y; AI and synthetic outputs are always marked as such.        
       37 +- **Machines propose, people decide.** Model output stays priv
          +ate and provisional until a person approves a revision. Later 
          +corrections create new revisions; they never rewrite an approv
          +al.                                                           
       38 +- **Rights fail closed.** Unknown rights block the action in q
          +uestion. Permission to publish, to send material to a remote m
          +odel, and to use it for AI training are separate decisions.   
       39 +- **Local first.** The application runs on loopback with an em
          +bedded database and plain files. No model service is contacted
          + unless an operator configures one, and nothing falls back sil
          +ently from a local model to a remote one.                     
       40 +- **Small, auditable supply chain.** Application code is Apach
          +e-2.0 with zero npm runtime dependencies.                     
       41 +- **Honest claims.** Release notes state what was verified and
          + how. Model accuracy, accessibility conformance and standards 
          +compliance are not claimed without their own evidence.
